Open Source — pick it up and run

Both repos are headed to MIT over time. The formats, the parsers, the tools — take them, fork them, build on them.

Fountain-Plus

Fountain-Plus is the open spec and reference parser for an extended Fountain syntax. It adds pages, panels, tags, and storyboard metadata on top of vanilla Fountain — every valid Fountain file is still a valid Fountain-Plus file. The repo ships the parser, formatter, and writers for PDF, Final Draft, FadeIn, and Fountain.

github.com/pistoltaeja/Fountain-Plus
MIT — soon

Mangaplay

The .mangaplay format and its formatter — a Fountain-Plus superset built for manga, comics, and webtoons. Pages, panels, panel tags, and reading direction baked in. The repo holds the syntax reference and the formatter that powers Mangaplay Studio.

github.com/pistoltaeja/mangaplay
MIT — soon
